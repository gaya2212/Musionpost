# Design assets

Drop design reference files here — Figma exports, component SVGs
(buttons, inputs, checkboxes, etc.), screen mockups, style sheets.
Organize however's convenient, e.g.:

```
design-assets/
  components/
    button.svg
    checkbox.svg
    radio.svg
    text-field.svg
  screens/
    dashboard.png
    projects.png
```

Point me at a file path when you want a component or screen rebuilt to
match it exactly, instead of pasting the file into chat — pasted files
aren't saved anywhere, so they can't be revisited or diffed against
later. Files here are checked into git, so keep anything sensitive out.
